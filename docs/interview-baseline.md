# Evidra 面试项目基线

> 基线分支：`feature/evidra-interview-ready`  
> 基线日期：2026-10-01  
> 说明：本文件只记录当前代码和验证状态，不代表已经完成外部服务或真实用户验收。

## 已完成的产品闭环

- 文章标题、正文、日期输入与前端校验。
- 创建分析会话、显示分析进度、四维 GEO 评分。
- 用户问题预测、逐题 Evidence 诊断、风险等级、缺失信息和修改建议。
- 复制/导出建议，修改正文后重新分析，以及当前浏览器会话内的 Before/After 总分和四维评分比较。
- 分析中、成功、局部失败、整体失败、超时、无效 JSON、重复提交和重试状态。
- Demo 固定样本与真实模型/安全降级/失败状态的明确区分。
- 首页、报告、诊断、建议、反馈、隐私、条款页面和 390px 移动端布局。

## 已完成的可靠性边界

- 请求体大小与 gzip 解压限制。
- 模型 JSON 和 Evidence 结构校验。
- 模型调用超时、失败、单条诊断重试和重新分析。
- 匿名安全日志；不记录正文、Prompt、Evidence、API Key 或原始身份值。
- `/api/health` 与 `/api/warmup` 健康/预热接口。
- 未配置模型时使用明确标识的安全降级结果，不伪装成真实模型结果。

## 当前代码验证

已通过：

```text
npm run typecheck
npm run lint
npm test
npm run security:unit
npm run build
git diff --check
```

本轮在当前执行环境重新运行了上述静态门禁，结果全部为退出码 `0`。当前可用运行时为 Node `v24.14.0`，仓库声明的 Node `22.23.x` 在本机没有可切换安装，因此 Node 22 专项复验仍未完成。

`npm run blackbox` 已尝试，但当前执行环境禁止连接 `127.0.0.1:3000`（`EPERM`），因此不能把本次执行记为黑盒通过。此前已有 15 项黑盒通过记录。

本轮黑盒前尝试启动 `npm run dev` 也被同一沙箱策略阻止：Next.js 无法监听 `0.0.0.0:3000`。这属于执行环境限制，不是应用返回的业务错误；需要在允许本地端口或 Preview URL 的环境中复验。

## 尚未完成或尚未真实验证

- Node 22.23.1 下的完整本地黑盒复验；当前终端为 Node 24.14.0。
- DeepSeek/兼容模型真实密钥、Upstash Redis 和 Preview 环境集成。
- 真实模型来源、Redis 限流模式和远程 Preview smoke。
- 公开 Preview 发布、5 分钟可重复演示和移动端真实设备验收。
- 真实用户访问/提交数据、至少一轮用户反馈和基于反馈的修复。

## 明确不在本阶段

不新增 Redis 配额体系、Sentry 运营平台、账户/协作、支付、复杂指标平台或大规模 UI 重构。Production 保持锁定。

## 停止条件

核心分析流程稳定、失败和重试可用、Evidence 与原文关系清楚、至少一轮真实用户测试完成并据此修复一次、面试演示可重复完成后，停止功能开发，转入面试材料整理和 UI 精修。
